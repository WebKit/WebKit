Testing that SpatialVideoSupport reports whether it is rendering, which is how fullscreen learns that a drag belongs to the projection's camera rather than to the dismissal gesture.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


Enabling the renderer reports that it is active:
PASS support._active is true
PASS reported is [true]

Tearing it down reports that it is not:
PASS support._active is false
PASS reported is [true, false]

Re-enabling reports again, so the state cannot be left stale across a fullscreen transition:
PASS support._active is true
PASS reported is [true, false, true]

A video that opts out never reports itself active:
PASS optedOutSupport._active is false
PASS optedOutReported is []
PASS successfullyParsed is true

TEST COMPLETE
