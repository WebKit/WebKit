Dragging a selection end grabber in a frame nested inside a same-site iframe should extend the selection to the line under the finger. All the frames are same-site, so this is the control for the tests where the middle frame or the nested frame is cross-site.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


PASS initialSelection is "token3"
PASS extendedSelection.startsWith('token3') is true
PASS endToken is "token6"
PASS successfullyParsed is true

TEST COMPLETE
