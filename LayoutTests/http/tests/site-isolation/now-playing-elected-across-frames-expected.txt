Under site isolation, the GPU process chooses the single system NowPlaying session across the main frame and its cross-site subframe. The main frame plays first and is selected; when the cross-site subframe then begins playing, the ConcurrentPlaybackNotPermitted restriction interrupts the main frame playback, and the GPU process selects the subframe's element instead.
