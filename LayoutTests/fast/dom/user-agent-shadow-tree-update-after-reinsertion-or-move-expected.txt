Tests that an input gets its shadow tree when it is removed and inserted again before many other inputs are inserted, or moved to another document and back, before a style update, that inputs inserted while many other inputs are inserted and removed around them all get their shadow trees, and that a use element that is listed twice around a use element it depends on shows the current content.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".

PASS hasShadowTree(movedBackInput) is true
PASS allHaveShadowTrees(keptInputs) is true
PASS outerUse.getBBox().width is 60
PASS successfullyParsed is true

TEST COMPLETE
