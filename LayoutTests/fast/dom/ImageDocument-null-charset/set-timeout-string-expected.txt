Tests that a string passed to setTimeout() in the window of an ImageDocument (a document without a text decoder, so with a null charset) runs. ScheduledAction runs the string through ScriptController::executeScriptInWorld(), which creates a CachedScriptFetcher from the document charset.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


PASS frameDocument.body.firstChild.tagName is "IMG"
PASS timeoutRan is true
PASS successfullyParsed is true

TEST COMPLETE
