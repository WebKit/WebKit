Tests that script elements inserted into an ImageDocument (a document without a text decoder, so with a null charset) run. ScriptElement::prepareScript() uses the document charset as the script's character encoding.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


PASS frameDocument.body.firstChild.tagName is "IMG"
PASS frameDocument.characterSet is "UTF-8"
PASS inlineScriptRan is true
PASS externalScriptRan is true
PASS successfullyParsed is true

TEST COMPLETE
