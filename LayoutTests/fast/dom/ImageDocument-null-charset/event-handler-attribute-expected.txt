Tests that an event handler content attribute set on an element of an ImageDocument (a document without a text decoder, so with a null charset) runs. JSLazyEventListener compiles the handler with a CachedScriptFetcher created from the document charset.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


PASS frameDocument.body.firstChild.tagName is "IMG"
PASS clickHandlerRan is true
PASS successfullyParsed is true

TEST COMPLETE
