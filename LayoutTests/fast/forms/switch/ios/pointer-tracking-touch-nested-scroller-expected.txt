A switch inside an overflow scroll area: that scroller gets first refusal, and once the switch has the touch the scroller stays out of it.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


An up drag, which the area can scroll:
PASS input.checked is false
PASS clicks is 0
PASS scroller.scrollTop > 0 is true
PASS Math.round(scrollY) is 0
A drag towards on, which the area cannot scroll sideways:
PASS input.checked is true
PASS clicks is 1
PASS scroller.scrollTop < 10 is true
A drag the area could scroll, after holding, which hands the touch to the switch:
PASS input.checked is true
PASS clicks is 1
PASS scroller.scrollTop < 10 is true
PASS successfullyParsed is true

TEST COMPLETE
