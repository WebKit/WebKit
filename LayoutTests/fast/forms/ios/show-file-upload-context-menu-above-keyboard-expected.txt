This test verifies that when programmatically clicking a file input while focusing an editable control with a software keyboard attached, the file upload context menu is presented above the software keyboard, and that the keyboard stays up while the menu is shown and after it is dismissed. To manually test, click the 'Show file picker' button without a hardware keyboard attached, and verify that the context menu is visible and that the keyboard stays up.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".
