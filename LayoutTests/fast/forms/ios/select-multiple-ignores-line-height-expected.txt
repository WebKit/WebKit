A select with the multiple attribute ignores line-height and has the same padding as one without, as both are dropdown boxes on iOS.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


PASS getComputedStyle(single).lineHeight is "normal"
PASS getComputedStyle(multiple).lineHeight is "normal"
PASS getComputedStyle(multiple).paddingInlineStart is getComputedStyle(single).paddingInlineStart
PASS successfullyParsed is true

TEST COMPLETE
