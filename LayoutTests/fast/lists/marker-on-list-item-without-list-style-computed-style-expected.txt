The ::marker of a list item without a list style has a computed style that follows the list item and Web Animations.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


getComputedStyle()
PASS markerColor(queriedEntry) is "rgb(0, 0, 255)"

Web Animation
animation = animatedEntry.animate({ color: ['rgb(255, 0, 0)', 'rgb(255, 0, 0)'] }, { duration: 1000000, pseudoElement: '::marker' })
PASS markerColor(animatedEntry) is "rgb(255, 0, 0)"
animation.cancel()
PASS markerColor(animatedEntry) is "rgb(0, 0, 255)"
PASS successfullyParsed is true
