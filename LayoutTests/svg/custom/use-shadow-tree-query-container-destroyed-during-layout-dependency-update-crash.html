Tests that an element recorded in Style::DocumentScope::LayoutDependencyUpdateContext survives until LocalFrameViewLayoutContext::layout() returns.

A <use> shadow tree clone can be a CSS query container, so invalidateForContainerDependencies() records it in LayoutDependencyUpdateContext::invalidatedContainers. That set lives on layout()'s stack across Document::updateStyleIfNeeded(), and SVGUseElement::updateUserAgentShadowTree() destroys and recreates the clone from inside that style update - so the recorded element dies while still referenced. With a CheckedRef this traps in CanMakeCheckedPtrBase::decrementCheckedPtrCount() when the sets are torn down.

Passes if it does not crash.
