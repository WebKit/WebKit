This test verifies that grammar correction UI is triggered when the caret moves into a word with a grammar marker after script changed the text, even if the previous caret offset now falls inside that word. This test requires WebKitTestRunner to run.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


PASS internals.hasGrammarMarker(4, 4) became true
PASS internals.isAlternativeTextUIActive() became true
PASS successfullyParsed is true

TEST COMPLETE
