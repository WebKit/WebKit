Tests that rechecking spelling drops the existing markers and marks the misspellings in the editable text that has spell checking enabled.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


A stale marker on a correctly spelled word goes away.
PASS spellingMarkerCount(editable.firstChild) is 1
PASS spellingMarkerCount(editable.firstChild) is 0

A misspelling that was never typed gets a marker.
PASS spellingMarkerCount(editable.firstChild) is 0
PASS spellingMarkerCount(editable.firstChild) is 1

Text that is not editable is not checked.
PASS spellingMarkerCount(editable.firstChild) is 0

A spellcheck=false descendant is not marked, and the text after it is.
PASS spellingMarkerCount(editable.childNodes[1].firstChild) is 0
PASS spellingMarkerCount(editable.lastChild) is 1

The text after a spellcheck=false descendant at the start is marked.
PASS spellingMarkerCount(editable.firstChild.firstChild) is 0
PASS spellingMarkerCount(editable.lastChild) is 1

Editable text inside a shadow tree is checked.
PASS spellingMarkerCount(shadow.firstChild.firstChild) is 1

A text control the user has interacted with is checked.
PASS internals.hasSpellingMarker(0, 2) is false
PASS internals.hasSpellingMarker(0, 2) is true
