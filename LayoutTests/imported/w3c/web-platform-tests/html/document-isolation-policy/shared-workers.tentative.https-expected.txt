Verify that Document-Isolation-Policy does not apply to Shared Workers by performing a cross-origin "fetch" request for a resource that does not specify CORP. A Shared Worker is in its own agent cluster and can use Cross-Origin-Embedder-Policy instead, so the request succeeds whether the policy is set on the worker script, its owner, or the creator of its URL.
