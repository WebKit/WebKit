A portal presented in a volumetric scene should return inline when its page is restored from the back/forward cache, so it is not stuck presenting a scene that was dismissed.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


PASS presentationMode(portal) is "volumetric"

Restored from the back/forward cache.
PASS presentationMode(portal) is "inline"
PASS portal.inVolumetricScene is false
PASS volumetricChangeCount became 2
PASS presentationMode(portal) is "volumetric"
PASS Re-entered a volumetric scene after restoring from the back/forward cache.
PASS presentationMode(portal) became 'inline'
PASS successfullyParsed is true

TEST COMPLETE
