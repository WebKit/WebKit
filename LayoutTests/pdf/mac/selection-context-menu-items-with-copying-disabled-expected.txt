Verifies that text selection items in a PDF context menu are present even when the document disallows copying.

On success, you will see a series of "PASS" messages, followed by "TEST COMPLETE".


Context menu for a selection in a PDF that disallows copying:
PASS hasMenuItem("Zoom In") is true
PASS hasMenuItemStartingWith("Look Up ") is true
PASS hasMenuItemStartingWith("Search with ") is true
PASS hasMenuItem("Copy") is false

Context menu for a selection in a PDF that allows copying:
PASS hasMenuItem("Zoom In") is true
PASS hasMenuItemStartingWith("Look Up ") is true
PASS hasMenuItemStartingWith("Search with ") is true
PASS hasMenuItem("Copy") is true
PASS successfullyParsed is true

TEST COMPLETE
