This tests that only activating a control that looks like it submits the fields around it starts a watch for errors, and that after anything short of a real submission only text colored as an error counts. A script calling click(), a control that expands something, and a button made into a tab submit nothing. Text a button writes under a field the user filled in, whether in a neutral color or in the amber of a warning, is status rather than an error. A search box in the page header is not part of the checkout below it, however the page wraps the two. The control that does submit still finds its errors afterwards.
