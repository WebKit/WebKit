Input method purpose and hints

Run MiniBrowser with --log-input-method and focus each field in turn. The page cannot read what WebKit reports to the input method, so compare the expected value for each field with the line MiniBrowser prints to the terminal:

input-method: focus in: purpose=... hints=...

Click an empty part of the page before each field. When focus moves straight from one field to another, WebKit does not send focus out and focus in, and MiniBrowser only prints a content type line if the purpose or hints change.

A field that is focused without user input, for example by script, also reports InhibitOSK.
