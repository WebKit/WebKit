This test checks that WTF::Collator's default locale follows the user's preferred language on macOS and iOS. WebKit sorts the subtitle tracks in the media controls' captions menu with that collator.

  1. Set the system language. On iOS, use Settings > General > Language & Region > Preferred Languages. On macOS, use System Settings > General > Language & Region > Preferred Languages. Quit and relaunch the browser after changing it.
  2. Load this page. Open the captions (subtitles) menu in the video's controls.
  3. Below "Off" and "Auto", the tracks should be in the order listed for that language.
Preferred languageExpected order
English, GermanAbisko, Åre, Örebro, Ostrava, Zagreb
Swedish, FinnishAbisko, Ostrava, Zagreb, Åre, Örebro
Danish, NorwegianAbisko, Ostrava, Zagreb, Örebro, Åre

Serve this page from a WebKit checkout so that the video loads, for example by running python3 -m http.server in the checkout's root directory and opening http://<host>:8000/ManualTests/media/caption-menu-sort-order.html.
