# API Test Blocklist
#
# Tests listed here run sequentially in the system shard after the parallel tests finish.
# Every other test runs in parallel. List a test here only when it can't run alongside
# other tests, and fix it rather than leaving it here when possible.
#
# Format: Both suite-level and test-level entries are supported:
#   - BINARY.SUITE - blocklists all tests in the suite, including ones added later
#   - BINARY.SUITE.TESTCASE - blocklists a specific test
#
# A test is blocklisted if either:
#   1. Its full name (BINARY.SUITE.TESTCASE) is in this list, OR
#   2. Its suite prefix (BINARY.SUITE) is in this list
#
# SUITE can contain slashes for parametrized tests (e.g., WTF_Int128IntegerConversionTest/0)
#
# Optional configuration gate: prefix a line with a bracketed token list to
# restrict the entry to a subset of ports. Recognized tokens include platform
# (ios, mac, watchos, tvos, visionos), style (debug, release, asan,
# guardmalloc), hardware (simulator, device), and architecture (arm64, x86_64).
# An ungated line applies to every port. Examples:
#     TestIPC.PortableTest
#     [ ios ] TestIPC.IOSOnlyTest
#     [ mac debug ] TestFoo.Bar
#
